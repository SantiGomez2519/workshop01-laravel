===============================================================================
                    INSTRUCCIONES PARA EJECUTAR EL PROYECTO RECLO
===============================================================================

Este documento contiene las instrucciones paso a paso para configurar y ejecutar
el proyecto Reclo - Sistema de Gestión de Usuarios desarrollado en Laravel.

===============================================================================
                                PRERREQUISITOS
===============================================================================

Antes de comenzar, asegúrate de tener instalado:

1. PHP 8.1 o superior
2. Composer (gestor de dependencias de PHP)
3. MySQL 5.7 o superior (o MariaDB)
4. Git (para clonar el repositorio)

NOTA: No se requiere Node.js ni npm ya que el proyecto usa CDNs para Bootstrap,
Font Awesome y Google Fonts.

===============================================================================
                                INSTALACIÓN
===============================================================================

PASO 1: CLONAR EL PROYECTO
---------------------------
Si tienes el proyecto en un repositorio Git:
git clone [URL_DEL_REPOSITORIO]
cd taller01

Si ya tienes los archivos del proyecto, navega a la carpeta:
cd ruta/a/tu/proyecto/taller01

PASO 2: INSTALAR DEPENDENCIAS DE PHP
------------------------------------
Ejecuta el siguiente comando en la terminal:
composer install

PASO 3: CONFIGURAR EL ARCHIVO DE ENTORNO
----------------------------------------
Copia el archivo de ejemplo:
cp .env.example .env

Edita el archivo .env con tu configuración de base de datos:
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=reclo_db
DB_USERNAME=tu_usuario
DB_PASSWORD=tu_contraseña

PASO 4: GENERAR CLAVE DE APLICACIÓN
-----------------------------------
Ejecuta el siguiente comando:
php artisan key:generate

PASO 5: CREAR LA BASE DE DATOS
------------------------------
Crea una base de datos MySQL llamada "reclo_db" (o el nombre que hayas configurado)

PASO 6: EJECUTAR MIGRACIONES
-----------------------------
Ejecuta el siguiente comando para crear las tablas:
php artisan migrate

PASO 7: EJECUTAR SEEDERS (OPCIONAL)
-----------------------------------
Para poblar la base de datos con datos de prueba:
php artisan db:seed

===============================================================================
                                EJECUCIÓN
===============================================================================

PASO 8: INICIAR EL SERVIDOR
---------------------------
Ejecuta el siguiente comando:
php artisan serve

El servidor se iniciará en: http://localhost:8000

===============================================================================
                                NAVEGACIÓN
===============================================================================

Una vez que el servidor esté ejecutándose, puedes acceder a:

- Página principal: http://localhost:8000/
- Crear usuario: http://localhost:8000/custom-users/create
- Listar usuarios: http://localhost:8000/custom-users/list

===============================================================================
                                FUNCIONALIDADES
===============================================================================

El sistema incluye las siguientes funcionalidades:

1. PÁGINA DE INICIO
   - Vista principal con información del sistema
   - Navegación a las diferentes secciones
   - Lista de usuarios recientes

2. CREAR USUARIO
   - Formulario para registrar nuevos usuarios
   - Validación de datos en tiempo real
   - Campos: nombre, teléfono, email, contraseña, método de pago

3. LISTAR USUARIOS
   - Tabla con todos los usuarios registrados
   - Enlaces para ver detalles de cada usuario
   - Navegación fácil entre secciones

4. VER DETALLES
   - Información completa de cada usuario
   - Opción para eliminar usuarios
   - Navegación de regreso a la lista

5. ELIMINAR USUARIO
   - Confirmación antes de eliminar
   - Redirección automática después de eliminar

===============================================================================
                                SOLUCIÓN DE PROBLEMAS
===============================================================================

PROBLEMA: Error de permisos
SOLUCIÓN: Asegúrate de que las carpetas storage y bootstrap/cache tengan permisos de escritura

PROBLEMA: Error de conexión a la base de datos
SOLUCIÓN: Verifica que MySQL esté ejecutándose y que las credenciales en .env sean correctas

PROBLEMA: Error de dependencias
SOLUCIÓN: Ejecuta "composer install" nuevamente

PROBLEMA: Página en blanco
SOLUCIÓN: Verifica los logs en storage/logs/laravel.log

PROBLEMA: Estilos no se cargan
SOLUCIÓN: Verifica tu conexión a internet (Bootstrap y Font Awesome se cargan desde CDN)

===============================================================================
                                COMANDOS ÚTILES
===============================================================================

- Limpiar caché: php artisan cache:clear
- Limpiar configuración: php artisan config:clear
- Limpiar rutas: php artisan route:clear
- Limpiar vistas: php artisan view:clear
- Ver rutas: php artisan route:list
- Ejecutar tests: php artisan test
